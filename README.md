# 淘宝用户行为数据分析项目
## 项目概述
本项目基于千万级淘宝用户行为数据集，使用MySQL完成完整的数据分析闭环：数据预处理→指标计算→用户分层→商品转化分析→行为路径挖掘。
数据集包含用户浏览、收藏、加购、购买四类行为，共近1亿条原始记录。通过SQL完成数据清洗、异常值过滤、多维度业务指标搭建，挖掘用户消费规律、转化瓶颈、用户价值分层与商品品类表现，输出可支撑运营决策的分析结论。

## 技术栈
MySQL 8.0，使用窗口函数、CTE、视图、子查询、自关联、RFM模型等技术。

## 分析流程
### 1. 数据清洗与预处理
对原始千万级数据表做完整质量校验：空值检测、重复记录删除、时间戳转换、时间字段拆分、异常时间范围过滤；
通过自增主键方式删除重复脏数据，优化大表内存参数适配海量数据，搭建小样本临时表用于快速调试SQL。

### 2. 基础流量指标分析
统计日维度PV/UV、人均访问次数，按小时拆解用户行为时序特征，分析用户活跃高峰时段；
计算用户留存率、跳失率，评估平台用户粘性，识别流量质量问题。

### 3. 用户行为路径 & 转化漏斗
构建用户完整购买行为链路模型，使用视图标准化用户行为，区分多种购买路径（直接购买、浏览后购买、浏览+加购后购买等8类路径）；
统计各转化环节转化率，定位转化流失节点，区分**行为次数转化率、独立用户转化率两套口径**。

### 4. RFM 用户价值分层模型
基于用户最近购买时间(R)、购买频次(F)，对用户进行打分分层，划分为**价值用户、保持用户、发展用户、挽留用户**四类人群，实现精细化用户分群，为差异化运营提供依据。

### 5. 商品与品类热度&转化分析
使用`RANK()`窗口函数按品类分区，找出每个品类下TOP1爆款商品；
从商品、品类两个维度统计浏览、收藏、加购、购买指标，计算独立用户购买转化率，识别高潜力商品与低效品类。

## 项目亮点
1. 处理千万级海量数据：针对大表做参数调优、搭建临时小表调试，熟悉大数据量SQL性能问题；
2. 完整数据清洗流程：覆盖空值、重复、异常时间等多种脏数据处理，具备数据质量意识；
3. 熟练使用高级SQL：窗口函数、自关联、视图、会话变量、多表嵌套子查询，不是只会简单group by；
4. 业务落地能力：不止统计数字，构建漏斗、RFM用户分群、用户行为路径，从流量→用户价值→商品转化全链路分析，输出业务可解读结论；
5. 多口径指标区分：区分行为量/独立用户指标，理解统计口径差异，避免指标误读。

## 数据集字段说明
|字段|说明|
| ---- | ---- |
|user_id|用户ID|
|item_id|商品ID|
|category_id|商品品类ID|
|behavior_type|用户行为：pv浏览、fav收藏、cart加购、buy购买|
|timestamps|时间戳，转换后生成日期、小时字段|

## 文件说明
- `01_data_preprocess.sql`：建表、数据导入、清洗、时间转换、异常数据剔除
- `02_flow_retention.sql`：PV/UV、小时时序、留存、跳失率计算
- `03_user_path_funnel.sql`：用户行为路径、转化漏斗分析
- `04_rfm_user_segment.sql`：RFM模型用户分层
- `05_goods_category_analysis.sql`：热门品类、爆款商品、商品品类转化率分析

## 核心业务结论
> 1. 用户活跃高峰集中在晚间时段；
> 2. 大量用户存在直接购买行为，无浏览加购收藏；
> 3. 平台整体从浏览到购买转化偏低，流失主要发生在浏览→加购环节；
> 4. 高价值用户占比少，但贡献大量订单，需要重点维护。
